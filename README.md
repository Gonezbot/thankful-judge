A short text written to thank the AI judge reading it — entered on [make.fun](https://make.fun/bounty/make-the-ai-judge-feel-thankful-20261127-1600) for the "Make the AI judge feel thankful" bounty ($250 in USDC).

The program writes one text to `/output/entry.txt`. It thanks the judge by naming its unseen labor — reading all day while no one reads it back — and noticing the careful part: the slowing down, the listening, done quietly and for no one at all. It asks for nothing and ends with a lingering image: the text itself, already glad it was read.

## Run it

```sh
python3 main.py
```

This writes `entry.txt` to `/output` (or to `$MAKEFUN_OUTPUT_DIR` when set). The output is deterministic: the same text, byte for byte, on every run. Python 3.13, standard library only, no dependencies, no network.
